# Кубик — мастерская 3D

Русскоязычный курс Blender 5.2 LTS для детей **6–10 лет**: короткие творческие миссии и смешные герои из простых форм.

- 10 тематических недель; **первые две недели готовы**, остальные — план.
- 4 встречи в неделю, ориентир **15–25 минут с перерывом**.
- 6–7 лет: вместе со взрослым. 8–10 лет: пробуем самостоятельно с доступной помощью.
- В первой неделе узнаём, как один куб становится разными деталями при изменении размера и места; собираем робота, выбираем цвет и имя. Фото — необязательная часть со взрослым.
- Во второй неделе узнаём, как цилиндр, конус и их пропорции меняют силуэт ракеты; добавляем стабилизаторы и иллюминатор, придумываем пассажира и сохраняем файл.
- Интерфейс на русском; названия команд Blender на английском с пояснениями.
- У каждого нового действия есть раскрываемая подсказка «Покажи мне» с настоящими скриншотами Blender 5.2. Нажмите на снимок для увеличения.
- В шапке страниц есть переключатель светлой и тёмной темы. Выбор сохраняется в этом браузере; без доступа к хранилищу действует до перезагрузки страницы.

## Открыть

[GitHub Pages](https://zu50052f.github.io/blender-course/) публикуется workflow при push в `main`. Изменения в ветке появятся на опубликованном сайте после слияния.

Для локального просмотра:

```sh
python3 -m http.server 8080 --directory site
```

Откройте `http://localhost:8080`. Сборка и backend не нужны.

## Устройства и офлайн

Blender работает на компьютере с клавиатурой и мышью. На iPad можно читать курс рядом с компьютером. В Safari: Поделиться → На экран «Домой».

Service Worker кэширует главную страницу, обе недели, стили, скрипты, иллюстрации и иконки. Скриншоты Blender добавляются в офлайн-кэш после первого просмотра каждого снимка. Офлайн доступен после успешной первой загрузки кэша. Внешние ссылки на документацию требуют сети.

У каждой недели свои восемь детских отметок в `localStorage`; прогресс ракеты не меняет прогресс робота. Они не синхронизируются между устройствами. Старые отметки версии для 10–14 лет не переносятся: задания изменились. Если хранилище недоступно, урок продолжает работать, а страница сообщает, что отметки временные.

Без JavaScript все четыре миссии видны подряд; сохранение прогресса недоступно. При печати выводятся все миссии.

## Файлы

```text
COURSE.md                   # Программа и подсказки взрослому
REVIEW.md                   # Что изменено после обзора исходной версии
site/
  index.html                # Карта приключений
  week-01.html              # Четыре миссии
  week-02.html              # Четыре миссии про ракету
  styles.css                # Общая светлая тема и адаптивная вёрстка
  course.js                 # Переходы, отметки и PWA-регистрация
  visual-guides.css/js      # Раскрываемые визуальные подсказки и просмотрщик
  theme.js                  # Переключение и сохранение темы
  service-worker.js         # Версионированный офлайн-кэш
  manifest.webmanifest
  assets/
    robot-mascot.jpg        # Иллюстрация для вдохновения
    rocket-mascot.svg       # Ракета для вдохновения
    step-1.svg … step-4.svg # Схемы форм
    blender/                # Настоящие снимки Blender 5.2 и их описание
    CREDITS.md
```

## Добавление недели

Сохраняйте русский язык и возраст 6–10 лет. На встречу — одна небольшая цель, короткий показ, собственный выбор, движение и сохранение. Сложные настройки помещайте в раскрываемую помощь для взрослого. Не включайте задачи преподавателя в детский прогресс.

Создайте страницу, обновите карточку, добавьте локальные ресурсы в `CORE_ASSETS` и измените `CACHE_NAME`. Используйте пути относительно страницы для GitHub Pages в подкаталоге. Не удаляйте кэши других приложений на том же origin.

Сверяйте команды и снимки с используемой версией Blender и проходите урок в самой программе перед занятием. Для недели 1 правьте `site/assets/blender/screenshots.json` и `tools/build-visual-guides.cjs`; для недели 2 — `site/assets/blender/rocket/screenshots.json` и `tools/build-rocket-guides.cjs`. После правки запустите соответствующий builder.

## Проверка изменений

Проверьте переходы между миссиями и назад, сохранение после перезагрузки, отказ хранилища, сброс с подтверждением, клавиатуру, узкий экран, iPad, печать и офлайн после установки Service Worker. Убедитесь, что изображения загружаются, локальные ссылки существуют, а обещания в COURSE.md совпадают с интерфейсом.

Для автоматических регрессионных проверок (только разработка, Node.js 22.13+):

```sh
npm ci
npm test
```

Проверки покрывают переключение темы и её сохранение, переходы, прогресс, отказ хранилища, сброс, локальные ссылки, офлайн-кэш и его очистку. Для статического сайта Node.js не нужен.
