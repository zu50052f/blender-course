# Visual assets

`step-1.svg` through `step-4.svg` are original course diagrams of simple shapes. They are not Blender screenshots or rendered student work.

`robot-mascot.jpg` was created with the built-in imagegen tool as an inspirational mascot. It is not presented as an achievable exact result of week one.

Generation prompt:

> Use case: stylized-concept. Asset type: hero illustration for a Russian Blender learning website for children aged 6–10. A charming friendly toy robot made of simple rounded lavender cuboids, peach-orange block arms and boots, large round cream eyes with dark purple pupils, a tiny smiling mouth and one yellow ball antenna. The robot waves one block arm happily. A few simple yellow sphere, peach cube and lilac cone building blocks next to its feet. Full body centered with generous margins, three-quarter view, isolated on a solid warm ivory #fff9ed backdrop with soft contact shadows. Beautiful tactile clay-like 3D toy render, sunny diffuse studio lighting, wholesome playful preschool museum aesthetic, polished yet simple forms. No text, no letters, no logos, no interface, no dark background. This is an inspirational mascot, not an exact lesson result. Square composition.

Original embedded pseudo-interface diagrams were removed. The screenshots in `blender/` are genuine captures of Blender 5.2.2 from a separate demo scene created for this course. Menu and file browser captures were taken from Blender’s own rendered UI; the browser screenshots were assembled from the UI regions without invented controls. Their JPEG files retain the real pixels. The lesson displays focused crops with CSS and leaves the full image available by clicking. The screenshots are examples; student models can differ. Official Blender documentation remains linked for adults.

The rocket lesson screenshots were also captured from a separate Blender 5.2.2 demo scene. Its cone fins and small cylinder engine illustrate how familiar primitives can give the rocket a more recognizable silhouette; the engine is optional in the lesson. The rocket mascot SVG is an original course illustration.

The generated PNG was exported as JPEG for a smaller offline download; the original generated file is retained outside the repository. App icons are original geometric cube drawings.

Week 5 airplane model views, including the transparent hero image used on the course map and lesson, were rendered in Blender 5.2.2 Workbench from a separate lesson scene by `tools/render-plane-guides.py`. They are Blender output images, not screenshots of the application interface. The `plane/12-add-modifier-panel.webp` and `plane/13-mirror-panel.webp` images are focused crops of real Blender 5.2.2 UI captures from a separate disposable lesson process, made with `tools/capture-plane-ui.py`. The application splash did not cover these panel regions. They help locate Add Modifier and the X axis switch.

Week 5 `14-cube-viewport.webp` through `21-extrude-viewport.webp` are actual Blender 5.2.2 viewport screenshots captured with `tools/capture-plane-viewport.py` in a separate disposable process. They retain real mode menus, selection, axes and object origins. Cropping is based on the viewport area, with no invented UI. The yellow origin pointer is an HTML overlay; the original pixels remain available on enlargement. The save-menu guide reuses the genuine Week 1 File menu screenshot; the instructions use `plane.blend`.

Week 6 `blender/colour/garden-*.webp` are real Blender 5.2.2 Material Properties and viewport screenshots captured by `tools/capture-colour-guides.py` in a disposable factory scene. They show the robot-gardener build in lesson order: primitive antenna, selected planter top, Inset, downward Extrude with a retained bottom, stem and sphere flower, copies, shared materials and optional Mirror gloves. Focused CSS crops and yellow HTML pointers guide the eye without replacing original pixels, available on enlargement. `garden-14-colour-hero.webp` is a transparent Cycles render of the same main project, without the optional gloves. New filenames keep offline caches from mixing old robot-only examples with the revised build. The save guide reuses the real Week 1 File menu with instructions for colour-lab.blend.
